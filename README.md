# Pixel Arcade

网页端红白机（NES）与街机（FBNeo）游戏平台，核心特色为 **WebRTC 无损像素串流联机**：由 P1 主机运行模拟器并按原生像素无损推送画面与音频，P2 访客无需下载 ROM 或加载模拟器核心，打开浏览器即可零门槛接收原画质画面并实时回传操作。

## 安装

环境要求：**Python 3.10+**（仅使用标准库，无需额外安装依赖）、**Node.js 18+**。

```bash
git clone https://github.com/radiumce/pixel-arcade.git
cd pixel-arcade
cd netplay-node && npm install && cd ..
```

## 局域网运行串流游戏

1. **启动服务**：在作为主机的电脑上运行一键脚本（默认监听局域网并开启局域网直连优化）：
   ```bash
   ./start.sh
   ```
   终端会自动输出局域网访问地址，形如 `http://<主机局域网IP>:8765`（如需停止后台服务运行 `./stop.sh`）。

2. **创建与加入房间**：局域网内的两台设备在浏览器中打开上述同一个 `http://<主机局域网IP>:8765`，进入 **联机房间**：
   - **P1 主机**：点击「创建房间」，在房间内上传或选择已保存的游戏 ROM 即可启动游戏。
   - **P2 访客**：输入 P1 页面显示的房间码，点击「加入房间」即可开始无损串流双人联机。
