游戏画面

NES 键位

方向键移动，J / K 为 B / A，Shift 为 Select，Enter 为 Start。

街机键位

方向键移动，Shift 投币，Enter 开始；动作键 J / K / L / I / O / P。不同游戏使用的动作键数量不同。

默认键位

P1：方向键 + J / K，Shift / Enter；P2：WASD + X / Z，I / U。

街机键位

P1：方向键，Shift 投币，Enter 开始，J / K / L / I / O / P 动作；P2：WASD，Q 投币，U 开始，X / Z / C / V / B / N 动作。
